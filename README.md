# Real Estate CRM Masterclass

This is the project folder for the **Real Estate CRM Masterclass** — a hands-on learning project for building a Real Estate CRM while learning Claude, Cowork, Claude Code, and AI-assisted software development.

## Stack

- **Frontend:** React + TypeScript
- **Backend:** Node.js + Express + TypeScript
- **Database:** PostgreSQL

## Structure (to be built progressively)

- `frontend/` — React + TypeScript client
- `backend/` — Node.js + Express + TypeScript API
- `docs/` — notes, decisions, and learning journal
- `CLAUDE.md` — project instructions for Claude Code (added later)

## Status

Project folder created. We'll build this stage by stage — nothing else has been scaffolded yet.
